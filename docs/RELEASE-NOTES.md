Moo is a personal fork of [Mue](https://github.com/mue/mue) for Firefox and Zen. New profiles and resets open in English with digital time, Search/Ask Bar, basic weather and Unsplash backgrounds. Enable other widgets in Settings. The 5 November rebuild includes the intervening feature and bug fixes and the shared Chrome build support. Selectable languages have complete key coverage, including machine-assisted translations that still need fluent-speaker review.

### Added

- Google widgets: read mail, manage tasks and check calendars using your own Google OAuth client. Calendar and Tasks accept English scheduling phrases with a review of the interpreted fields. Calendar adds recurring events, reminders, guests, attachments and a scrollable event preview with on-demand location maps. Background reminders use optional notification access. [Calendar](https://github.com/apoapostolov/Moo-New-Tab-for-Firefox/blob/v1.0.0/docs/GOOGLE-CALENDAR.md) · [Natural Format](https://github.com/apoapostolov/Moo-New-Tab-for-Firefox/blob/v1.0.0/docs/NATURAL-FORMAT.md).
- Search/Ask Bar: choose a search engine, AI service or reference site for a query. The menu remains available in smaller windows.
- Picture, video and live backgrounds: choose a source, upload pictures or add streams. Triple-click a playing video to hide the widgets; Escape restores them. Media cleanup and storage tests cover decoder sources, HLS players, subscriptions and asset lifetimes. The memory test runner uses a disposable browser profile. [Memory testing and limits](https://github.com/apoapostolov/Moo-New-Tab-for-Firefox/blob/v1.0.0/docs/MEMORY-TESTING.md).
- Widget layout: save separate Standard and Focus layouts, move widgets between columns and choose their panel styles. Focus sessions and Progress clock shifts activate the Focus layout. Bookmarks combines browser bookmarks, Raindrop and Readwise with shared previews and reading selections; Habits tracks confirmed days, streaks and milestones; GitHub shows review requests, issues, pull requests and workflow runs. [Bookmarks](https://github.com/apoapostolov/Moo-New-Tab-for-Firefox/blob/v1.0.0/docs/BOOKMARKS.md) · [Habits and GitHub](https://github.com/apoapostolov/Moo-New-Tab-for-Firefox/blob/v1.0.0/docs/HABITS-AIR-QUALITY-GITHUB.md).
- Clock and weather: choose clocks, world clocks, working hours and a five-day forecast. Air Quality shows European or US AQI with optional forecasts, pollutants, UV and pollen in Basic, Summary or Detailed views. [Time features](https://github.com/apoapostolov/Moo-New-Tab-for-Firefox/blob/v1.0.0/docs/TIME-AND-COUNTDOWNS.md).
- RSS reader: read feeds or connect Feedly, preview stories, and import or export OPML while preserving folders. Feedly reads use its unread list, mark opened stories read and report token usage in Settings.
- Floats and Quick Links: create floating notes, lists, images and countdowns, keep selected items fixed and choose which appear in Focus. Notes have an editor; countdown titles can be edited directly. Quick Links supports separate Focus/Work destinations and optional usage ordering while preserving manual order by default.
- Backups and browser development: export and preview imports of settings and uploaded pictures while keeping credentials separate. Both repositories build Firefox and Chrome from the same application and permission catalogue, with parity guidance and a sync check. Chrome uses a Manifest V3 service worker and its own Google OAuth redirect. README hero and preview assets are reused. [Firefox and Chrome development](https://github.com/apoapostolov/Moo-New-Tab-for-Firefox/blob/v1.0.0/docs/CROSS-BROWSER.md).

### Installation and verification

The ZIP and XPI contain the same unsigned Firefox extension. Extract `firefox-1.0.0.zip`, open `about:debugging` → This Firefox → Load Temporary Add-on, and select `manifest.json`. Temporary installation ends on restart. Zen builds that permit unsigned extensions can use Install Add-on From File with `moo-1.0.0.xpi`; permanent installation in standard Firefox requires Mozilla signing. Renaming an archive does not sign it.

The rebuild passes all 233 tests under Node 22, JavaScript and SCSS lint, both browser builds and both archive validators. An isolated installed Chromium check verifies new-tab startup, the extension API namespace, the Google redirect and asynchronous reminder messaging. Real Google account consent and operations and installed Firefox/Zen feature checks still need verification. Earlier memory measurements and their limits are in the memory testing guide; this release does not claim that the reported system exhaustion is resolved.
