# Google Drive

Open Settings → Google → Widget settings and choose Google Drive in the four-service selector. Enable it there or in Overview. It shares the existing Google connection. Enable the Google Drive API in the same Google Cloud project as Gmail, Calendar and Tasks, then reconnect Google to approve the new `drive.metadata.readonly` permission. Existing connections keep working for the other widgets; Drive asks for reconnection when its permission is missing.

Recent shows the most recently modified files. Starred and Shared filter that list; Search file names searches within the selected view or folder. Open a folder to browse it and use Back to return. Scroll to the bottom of the file list to load another page. The list also supports keyboard scrolling. Its scrollbar appears while scrolling or when the list has focus, then fades out when neither is active. File links open in a new tab, and the title opens Google Drive. Moo does not download file contents, upload, delete, rename or share files. Folder shortcuts open in Drive rather than being browsed inside the widget.

Files per page, refresh interval and Classic/Glass styling appear only when Google Drive is selected in Widget settings. Files per page also sets the visible list height: five means five complete file rows, with a shorter list when fewer files exist. More files remain available by scrolling. The last selected Recent, Starred or Shared view is remembered across reloads and sessions. Refresh checks the current view immediately. Drive also reloads when the tab becomes visible. Offline mode prevents API requests. Listings are kept in memory, discarded on account changes and excluded from Backups; visibility, placement and display settings are included. Standard and Focus layouts can show the widget independently.

Google Workspace administrators can restrict access to the API or OAuth scope. Follow the error from Google if a project or organization blocks access. This feature uses the same browser-specific OAuth client setup as the existing Google widgets.

API references: [Drive scopes](https://developers.google.com/workspace/drive/api/guides/api-specific-auth), [file listing](https://developers.google.com/workspace/drive/api/reference/rest/v3/files/list) and [filename searches](https://developers.google.com/workspace/drive/api/guides/search-files).
